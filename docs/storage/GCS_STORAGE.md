# GCP Cloud Storage

## Buckets
The application uses two buckets:
1. **Public Bucket**: Pre-configured with uniform bucket access and `allUsers` IAM role. Files are world-readable and accessible via `storage.googleapis.com`.
2. **Private Bucket**: Requires V4 Signed URLs generated by the FastAPI backend for temporary, secure access.

## Local Development
Local dev requires a GCP Service Account JSON key exported via `GOOGLE_APPLICATION_CREDENTIALS` env var. Cloud Run handles this automatically.
